# Daily Workflow — How to Use the Lab

Stop wondering what to do. Follow the playbook.

---

## Philosophy

**Consistency beats intensity.** 30 minutes daily beats 8 hours once a week.

**Three patterns:**
- **30-minute day** — Busy, minimal time
- **1-hour day** — Standard study day
- **2-hour day** — Deep work day

Pick what fits your day. Show up consistently.

---

## 30-Minute Day

| Time | Activity |
|------|----------|
| 0-5 min | Open lab, check notifications, `git pull` |
| 5-20 min | One focused topic (see per-cert sections) |
| 20-25 min | Practice one command or technique |
| 25-30 min | Document findings, commit to GitHub |

**Best for:** Busy weekdays

---

## 1-Hour Day

| Time | Activity |
|------|----------|
| 0-5 min | Open lab, `git pull`, review yesterday |
| 5-25 min | Theory study (video, book, docs) |
| 25-50 min | Hands-on practice (VM, challenge, command) |
| 50-60 min | Document, commit, plan tomorrow |

**Best for:** Standard workdays

---

## 2-Hour Day

| Time | Activity |
|------|----------|
| 0-10 min | Open lab, review yesterday, plan today |
| 10-40 min | Theory (deep focus) |
| 40-90 min | Hands-on lab (VM, CTF, challenge) |
| 90-110 min | Advanced practice or tool building |
| 110-120 min | Document, commit, plan tomorrow |

**Best for:** Weekends, deep learning days


---

## Weekly Pattern

### Monday to Friday

| Day | Focus |
|-----|-------|
| Monday | Theory — new concepts |
| Tuesday | Theory — deepen understanding |
| Wednesday | Hands-on — basic practice |
| Thursday | Hands-on — intermediate |
| Friday | Challenge — real scenario |

### Saturday

| Time | Activity |
|------|----------|
| Morning | Long lab session (2-4 hours) |
| Afternoon | Write up findings |
| Evening | Plan next week |

### Sunday — Rest or Light Review

| Time | Activity |
|------|----------|
| 30 min | Review week's progress |
| 30 min | Plan next week's focus |
| Rest | Recharge |

---

## Monthly Pattern

### Week 1 — Foundation

- Focus: New topic or cert domain
- Activities: Theory, reading, videos
- Output: Notes in docs/

### Week 2 — Practice

- Focus: Hands-on repetition
- Activities: Labs, challenges, commands
- Output: Screenshots in /data/evidence/

### Week 3 — Application

- Focus: Real scenarios
- Activities: CTFs, bug bounty, HTB
- Output: Writeups in /data/cybersecurity/

### Week 4 — Review

- Focus: Solidify learning
- Activities: Review notes, mock tests
- Output: Summary, next month plan

## Cert Study Days

### RHCSA Day (1 hour)

| Time | Activity |
|------|----------|
| 0-15 min | Read RHCSA topic (from docs/01) |
| 15-45 min | Practice commands in terminal |
| 45-60 min | Document, update progress tracker |

**Focus:** 5-6 commands per day. Master them.

### OSCP Day (2 hours)

| Time | Activity |
|------|----------|
| 0-30 min | Recon a new HTB box |
| 30-60 min | Enumerate services |
| 60-90 min | Exploit and get shell |
| 90-110 min | Privilege escalate |
| 110-120 min | Write walkthrough, commit |

**Focus:** 1 box per day. Learn from failure.

### Blue Team Day (1 hour)

| Time | Activity |
|------|----------|
| 0-20 min | Analyze logs from a dataset |
| 20-40 min | Write detection rule (Sigma) |
| 40-60 min | Document, commit |

**Focus:** 1 detection per day.
