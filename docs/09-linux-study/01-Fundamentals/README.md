# Linux Fundamentals

This module establishes the core Linux knowledge required for system administration, cybersecurity, software engineering, automation, and security research.

## Learning Objectives

By completing this module, you should be able to:

- Explain what Linux is and how a Linux system is organized.
- Understand the relationship between the kernel, shell, utilities, and applications.
- Navigate and work effectively from a terminal.
- Use essential Linux commands confidently.
- Read command documentation and manual pages.
- Create, inspect, modify, and organize files and directories.
- Understand standard input, standard output, and standard error.
- Use pipes and redirection to compose commands.
- Understand environment variables and the command environment.
- Solve practical command-line problems independently.

## Modules

1. `01-Linux-Architecture` — Kernel, user space, processes, system components, and Linux distributions.
2. `02-Terminal-and-Shell` — Terminal, shell, Bash, prompts, and command execution.
3. `03-Essential-Commands` — Core commands used every day.
4. `04-Help-and-Manuals` — `man`, `info`, `--help`, documentation, and command discovery.
5. `05-Files-and-Directories` — Creating, copying, moving, removing, and inspecting filesystem objects.
6. `06-Input-Output` — Standard input, output, error, and file descriptors.
7. `07-Pipelines-and-Redirection` — Combining commands and controlling data flow.
8. `08-Environment-and-Variables` — Variables, `PATH`, shell environment, and command behavior.
9. `09-Command-Line-Skills` — Practical command-line problem solving.
10. `10-Exercises` — Hands-on exercises and assessments.
11. `11-Notes` — Supporting notes and references.

## Method

For each topic:

1. Learn the concept.
2. Demonstrate it in the terminal.
3. Complete an exercise.
4. Document what was learned.
5. Troubleshoot at least one problem.
6. Review and reinforce the knowledge.

## Completion Criteria

The module is complete when the learner can perform common Linux tasks from the command line without relying on step-by-step instructions for every operation.
