# Project 01 — Linux

## Purpose

This project builds a strong Linux foundation for cybersecurity, software engineering, system administration, automation, and security research.

Linux is the foundation on which many cybersecurity tools, servers, cloud systems, security appliances, and laboratory environments operate.

## Objectives

- Understand Linux architecture and core concepts.
- Become comfortable working entirely from the command line.
- Master files, directories, users, groups, and permissions.
- Understand processes, services, networking, and system administration.
- Learn Bash and Linux automation.
- Understand Linux security fundamentals.
- Build practical administration and security skills through controlled labs.
- Document commands, experiments, findings, and research.

## Project Structure

- `01-Fundamentals` — Linux concepts and essential commands.
- `02-Filesystem` — Filesystem hierarchy, files, directories, links, and storage.
- `03-Users-and-Groups` — Accounts, groups, ownership, and identity management.
- `04-Permissions` — Linux permissions, special permissions, and access control.
- `05-Processes-and-Services` — Processes, jobs, signals, systemd, and services.
- `06-Networking` — Linux networking concepts and network administration.
- `07-Bash-and-Shell` — Shell usage, pipelines, redirection, variables, and command composition.
- `08-Package-Management` — Packages, repositories, updates, and software management.
- `09-System-Administration` — System configuration, logs, storage, scheduling, and administration.
- `10-Linux-Security` — Hardening, auditing, access control, and security fundamentals.
- `11-Tools` — Security and administration tools used in Linux environments.
- `12-Scripting` — Bash and other scripting for automation.
- `13-Labs` — Hands-on controlled exercises and experiments.
- `14-Notes` — Personal learning notes and command references.
- `15-Research` — Linux security research, experiments, and technical investigations.

## Methodology

Learn → Practice → Document → Test → Review → Automate → Research

Every major topic should contain practical work where appropriate rather than only theoretical notes.

## Scope

All security experimentation in this project should be performed on systems and environments that are owned by the user or explicitly authorized for testing.

Project 01 is under active development.
