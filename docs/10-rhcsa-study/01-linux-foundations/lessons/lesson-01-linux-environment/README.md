# Lesson 1 — Linux Environment & Security Lab

## Purpose

Establish a practical understanding of the Linux environment before progressing
into RHCSA system administration topics.

This lesson introduces:

- Linux system identification
- Linux filesystem hierarchy
- Users and groups
- Privileges and sudo
- Processes and process relationships
- File and directory permissions
- Security observations
- Controlled permissions laboratory work

## Learning Method

Each lesson follows:

1. Concept
2. Why it matters
3. Demonstration
4. Hands-on practice
5. Challenge
6. Verification
7. Documentation
8. Final review

## RHCSA Relevance

This lesson establishes foundations used throughout RHCSA preparation,
particularly:

- Essential tools
- File and directory operations
- Users and groups
- File permissions
- Running systems
- Process inspection
- Command-line administration

## Security Relevance

Security concepts are introduced only as supporting knowledge.

This lesson does not attempt exploitation. It focuses on understanding:

- privilege boundaries
- ownership
- permissions
- process ownership
- executable ownership
- directory permissions
- least privilege
- evidence-based security observations
