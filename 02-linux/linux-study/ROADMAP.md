# Linux Roadmap

## Phase 1 — Fundamentals
- Linux architecture
- Terminal and shell
- Essential commands
- Help systems and manual pages
- Files and directories
- Input/output and command composition

## Phase 2 — Filesystem and Access Control
- Filesystem hierarchy
- File types
- Links
- Ownership
- Users and groups
- Permissions
- Special permissions

## Phase 3 — Processes and System Management
- Processes
- Jobs
- Signals
- Services
- systemd
- Logs
- Scheduling

## Phase 4 — Networking
- Interfaces
- IP addressing
- Routing
- DNS
- Ports and sockets
- Network troubleshooting

## Phase 5 — Bash and Automation
- Variables
- Conditions
- Loops
- Functions
- Pipes
- Redirection
- Shell scripting
- Automation

## Phase 6 — Linux Security
- System hardening
- Authentication
- Access control
- Secure configuration
- Auditing
- Logging and monitoring
- Security tooling

## Phase 7 — Practical Labs
Build controlled labs covering:
- System administration
- Permissions
- Networking
- Bash automation
- Security configuration
- Troubleshooting

## Phase 8 — Research
Investigate Linux security concepts, vulnerabilities, defensive techniques, tooling, and emerging technologies.

## Completion Standard

A topic is considered learned when it can be:

1. Explained clearly.
2. Demonstrated from the terminal.
3. Applied in a controlled lab.
4. Documented.
5. Troubleshot when something goes wrong.
6. Automated where appropriate.
