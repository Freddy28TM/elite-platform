## Part 1 — Shell Basics

### What is a Shell?

The shell is the interface between you and the Linux kernel.

Common shells:
- bash (Bourne Again Shell) — default on most systems
- sh (Bourne Shell) — original
- zsh, fish, ksh — alternatives

### Current Shell

Check with: echo $SHELL

### Key Concepts

- Commands are programs
- Shell interprets commands
- Shell provides scripting
