# Lesson 02 — Shell and Command Line

**Module:** 02-shell-and-command-line
**Status:** In Progress
**Started:** 2026-10-11

---

## Overview

Master the shell environment and essential text-processing commands.

This lesson covers the commands you will use every single day as a Linux administrator.

---

## Essential Commands (5)

| # | Command | Purpose |
|---|---------|---------|
| 1 | echo | Output text |
| 2 | cat | View files |
| 3 | less | Paginated view |
| 4 | grep | Search text |
| 5 | find | Find files |

Plus: pipes (`|`), redirection (`>`, `>>`, `<`)

---

## Learning Objectives

By the end of this lesson, you will:
- [ ] Understand the shell environment
- [ ] Output and manipulate text with echo
- [ ] View files with cat and less
- [ ] Search text with grep
- [ ] Find files with find
- [ ] Chain commands with pipes and redirection
